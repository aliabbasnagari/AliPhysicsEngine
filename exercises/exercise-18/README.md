# Exercise 18 — Capstone: God-Level Demo

**Tier:** 7 — Capstone
**Prerequisites:** Everything. This is the finish line.

Seventeen modules of engine-building later, this module is about turning
it into something real: a scene you can save/load, tools to build and tune
scenes interactively, an actual demo that exercises the whole engine, and a
final, honest accounting of its limits.

## What you'll build

Scene serialization, interactive sandbox tooling, a complete demo
(stacking tower, Newton's cradle, or a small physics-driven game — your
choice), and a stress-test report.

## Files you'll touch

- New `src/core/Serialization.h` / `.cpp`
- `src/sandbox/Sandbox.h` / `.cpp`
- Whatever new demo-specific files your chosen demo needs
