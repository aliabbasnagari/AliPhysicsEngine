# Exercise 1 — Math Foundations

**Tier:** 0 — Foundations
**Prerequisites:** none

Every physics engine is built on a small set of math primitives used
everywhere else. Get these right (and well-tested by eye/print statements)
before touching anything else - bugs here silently corrupt every later
module.

## What you'll build

A header-only 2D/3D math library: `Vec2`, `Vec3`, `Mat4`, `Quaternion`.

## Files you'll touch

- `src/math/Vec2.h`
- `src/math/Vec3.h`
- `src/math/Mat4.h`
- `src/math/Quaternion.h`
