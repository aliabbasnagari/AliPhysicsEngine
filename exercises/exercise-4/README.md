# Exercise 4 — Springs & Particle Constraints

**Tier:** 1 — Particle Physics
**Prerequisites:** Exercise 3

You've already built a rope simulation once (see the git history of this
project) — this module rebuilds that idea properly, inside the engine
architecture, and extends it to cloth. This is also your first taste of
**constraint solving**, the technique that underlies most of the rigid body
work from Exercise 8 onward.

## What you'll build

Spring forces, position-based distance constraints, a rope made of
constrained particles, and a cloth grid.

## Files you'll touch

- `src/physics/PhysicsWorld.h` / `.cpp`
- `src/sandbox/Sandbox.h` / `.cpp`
